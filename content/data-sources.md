# Product data source hierarchy

Prefer, in order:
1. Direct marketplace product/listing data for current listing facts.
2. Manufacturer/brand sources for stable specifications and warranty details.
3. Independent price-history sources for historical price context.
4. Search snippets only as supporting discovery evidence, not as the sole basis for a fragile claim when a direct source can be checked.

Record the research date and distinguish observed marketplace facts from ValueRadar editorial interpretation.
