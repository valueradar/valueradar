# Automation roadmap

Current: research → products.json → generator/validation → static pages + sitemap → PR → GitHub Pages.

Next:
1. Generate homepage product cards/search index from the product database instead of maintaining them separately.
2. Generate social content queue and UTM URLs from product metadata/templates.
3. Add scheduled candidate discovery only where data-source terms and APIs permit it.
4. After affiliate approval, integrate compliant program APIs/feeds where available.
5. Add reporting that combines GA4 traffic/click data with affiliate reports without pretending attribution systems are identical.

Automation must preserve evidence checks; it should not auto-publish unsupported deal claims.
