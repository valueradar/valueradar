# ValueRadar project map

- `index.html` — public discovery homepage
- `products.json` — product source of truth
- `products/<slug>/index.html` — static SEO product pages
- `scripts/build_products.py` — validation/page/sitemap generator
- `scripts/check_catalogue.py` — catalogue integrity checks
- `sitemap.xml` / `robots.txt` — search discovery
- `content/` — operating policies, queues, analytics and growth plans
- `.github/workflows/` — automated validation
